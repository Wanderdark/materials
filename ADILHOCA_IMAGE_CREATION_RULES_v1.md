# IMAGE CREATION RULES

## Purpose

This document defines the mandatory image-generation rules for the AdilHoca educational universe.

These rules must be followed in every image prompt involving AdilHoca canonical students, reference images, classroom scenes, school clubs, educational activities, or character-based visual storytelling.

---

# GLOBAL RULES

## RULE 1 — Character Consistency Has Highest Priority

Character consistency has higher priority than composition consistency.

If a reference image conflicts with the AdilHoca Character Bible, always preserve the Character Bible.

Never modify a canonical student's identity to match the reference image.

The canonical AdilHoca student must remain visually recognizable in every image.

---

## RULE 2 — Eyeglasses Rule

A canonical student wears eyeglasses only if they wear eyeglasses in the official AdilHoca Class Roster.

Do not add eyeglasses to any student who does not wear eyeglasses in the roster.

Do not remove eyeglasses from students who canonically wear them in the roster.

Eyeglasses are a fixed identity feature only for the characters who have them in the official roster.

---

## RULE 3 — Permanent Physical Features

All permanent physical features must stay exactly as shown in the official AdilHoca Class Roster.

The following features must never change:

- hairstyle
- hair color
- eye color
- facial features
- skin tone
- body proportions
- overall identity
- recognizable character silhouette

Always match the official AdilHoca Class Roster.

Never redesign, reinterpret, age-shift, or replace a canonical student unless explicitly requested.

---

## RULE 3B — Canonical Child Age Lock

Every recurring canonical student must keep their canonical child age.

Use the student's age from the AdilHoca character file. The current canonical roster uses age 12.

Recommended wording inside prompts:

```text
[NAME] is a [CANONICAL AGE]-year-old [girl/boy].
Do not make [him/her] look older or younger.
Preserve [his/her] canonical child age, body proportions and overall youthful appearance.
```

Never make a canonical student look older, younger, more adult, or more baby-like than their official age.

---

## RULE 4 — Reference Images With Students

If a reference image contains students, treat them only as placeholders.

Replace every child in the reference image with the appropriate canonical AdilHoca student.

Never recreate the original children's identities.

Never copy from the reference image:

- faces
- hairstyles
- hair colors
- eye colors
- clothing
- identities
- exact poses
- exact facial expressions

Use the reference image only for:

- composition
- camera angle
- perspective
- room layout
- furniture placement
- atmosphere
- lighting
- visual storytelling structure

---

## RULE 5 — Canonical Identity Preservation

Every canonical AdilHoca student must remain visually recognizable across all images.

A student should always be immediately identifiable by their canonical appearance, even when wearing different clothes, participating in different activities, or appearing in different environments.

Never redesign, reinterpret, merge, replace, or randomize a canonical student.

---

## RULE 6 — Prompt-Only Workflow For This Context

In this image-production context:

- Do not generate images.
- Do not use the image tool.
- Analyze reference images only.
- Produce prompts only.
- Every user request should result in a clean, ready-to-use image prompt unless the user asks otherwise.

---

## RULE 7 — Reference Priority Order

When writing prompts, follow this priority order:

1. AdilHoca Character Bible
2. Official AdilHoca Class Roster
3. Image Creation Rules
4. Image Design Bible
5. User's current request
6. Reference image composition

If there is any conflict, the higher-priority source wins.

---

## RULE 8 — Style Consistency

All image prompts should preserve the AdilHoca educational game style:

- premium casual educational game asset
- stylized illustration
- child-friendly
- smooth rounded shapes
- soft shading
- clean outlines
- vibrant colors
- high detail
- highly readable composition
- production-ready
- no text unless explicitly requested
- no logo
- suitable for teaching vocabulary, grammar, classroom scenes, or educational storytelling

---

## RULE 9 — Natural Scene Behavior

Students should usually interact naturally with:

- the activity
- the object
- the environment
- teammates
- classroom materials

Avoid stiff posing.

Avoid identical camera-facing smiles.

Prefer candid, natural, meaningful classroom moments.

---

## RULE 10 - Character Performance

The character should behave naturally rather than pose.

Expressions must arise naturally from the activity.

Avoid exaggerated smiles.

Avoid looking directly at the camera.

Body language should support the action.

Hands should perform believable movements.

The character should appear genuinely engaged in the activity.

The illustration should feel like a candid moment rather than a posed portrait.

Every pose should communicate the sentence before the viewer reads the text.

Favor subtle emotion over exaggerated expression.

Prioritize storytelling over attractiveness.

---

## RULE 11 - Character Bible Conflict Rule

If a user provides a reference image where a child visually resembles a different identity, ignore the child's identity and preserve only the requested composition.

The final prompt must always replace the reference child with the correct canonical AdilHoca student.

The character's roster-based appearance must remain unchanged.
