# WORD CRUSH Gem Assets

Export each gem as a transparent PNG for now.

## Recommended Size

- `512 x 160 px`
- Keep the full gem inside the canvas with a small transparent margin.
- Use the same canvas size for every color so text placement stays stable.
- Before release, these can be converted to WebP for smaller downloads.

## Required Files

- `gem-red.png`
- `gem-green.png`
- `gem-blue.png`
- `gem-purple.png`
- `gem-black.png`

## Reserved Optional Files

- `gem-orange.png`
- `gem-yellow.png`
- `gem-cyan.png`

## Paths Used By CSS

- `assets/gems/gem-red.png`
- `assets/gems/gem-green.png`
- `assets/gems/gem-blue.png`
- `assets/gems/gem-purple.png`
- `assets/gems/gem-black.png`
- `assets/gems/gem-orange.png`
- `assets/gems/gem-yellow.png`
- `assets/gems/gem-cyan.png`

Normal mode uses these PNG assets. `body.lite-mode` keeps the CSS placeholder gems.
