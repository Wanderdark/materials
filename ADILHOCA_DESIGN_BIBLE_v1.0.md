# ADILHOCA DESIGN BIBLE v1.0

> Master visual and production guide for every asset used across the
> AdilHoca educational platform.
>
> **Project Scope:** Entire AdilHoca ecosystem (Word Gemoria is one
> module only)

------------------------------------------------------------------------

# 1. Vision

AdilHoca is a premium educational platform for English learners. Every
illustration, icon, UI component and game should feel like it belongs to
one shared universe.

Core goals:

-   Educational first
-   Fun without looking childish
-   Premium casual game quality
-   Extremely readable
-   Consistent visual identity
-   Production-ready assets

------------------------------------------------------------------------

# 2. Art Pillars

Every asset should be:

-   Premium casual
-   Stylized (never photorealistic)
-   Friendly
-   Bright
-   Optimistic
-   Educational
-   High readability
-   Clean silhouettes
-   Smooth rounded shapes
-   Vibrant colors
-   Soft shading

------------------------------------------------------------------------

# 3. Target Audience

Primary:

-   Ages 10--14

Secondary:

-   English teachers
-   Parents

Nothing should feel scary, violent or overly realistic.

------------------------------------------------------------------------

# 4. Universal Asset Rules

Unless explicitly overridden:

-   White background
-   Centered composition
-   Isolated object
-   No logo
-   No watermark
-   No text (unless requested)
-   High detail
-   Production-ready
-   Soft shadows only
-   Consistent perspective

------------------------------------------------------------------------

# 5. Character Bible

Children: - 10--12 years old - Friendly - Classroom-appropriate -
Rounded proportions - Natural expressions - Colorful clothing

Adults: - Approachable - Professional - Helpful - Never intimidating

Fantasy: - Friendly only - Bright magical effects - No horror

------------------------------------------------------------------------

# 6. Object Bible

Objects must be instantly recognizable.

Preferred: - Rounded corners - Slight 3/4 angle - Glossy finish - Strong
silhouette - Limited tiny details

------------------------------------------------------------------------

# 7. Educational Philosophy

Illustrations should teach.

Examples: - Big vs Small - Long vs Short - Heavy vs Light - Fast vs Slow

Action verbs should always show movement.

------------------------------------------------------------------------

# 8. UI Design Language

Rounded UI

Soft gradients

Gold = achievements

Blue = learning

Green = success

Red = mistakes only

Orange = adventure / campaign

Papyrus = titles

Crystal = rewards

------------------------------------------------------------------------

# 9. Icon Language

Readable at small sizes.

One clear concept.

No unnecessary decoration.

------------------------------------------------------------------------

# 10. Environment Design

Fantasy: - Crystal Kingdom - Magical forests - Gemstones - Warm lighting

Educational: - Schools - Parks - Homes - Libraries

Simple and readable.

------------------------------------------------------------------------

# 11. Achievement Design

Circular medals

Gold trim

Symmetrical

Readable ribbon

Strong central symbol

No clutter

------------------------------------------------------------------------

# 12. Prompt Template

Base prompt:

Premium casual educational game asset, stylized illustration,
child-friendly, smooth rounded shapes, soft shading, highly readable
silhouette, centered composition, isolated on white background, high
detail, production-ready.

------------------------------------------------------------------------

# 13. Negative Prompt

Avoid:

-   photorealistic
-   horror
-   gore
-   dirty textures
-   realistic skin pores
-   excessive shadows
-   tiny unreadable details
-   dark depressing palettes

# 17. Consistency Rules

Whenever a new asset is created, ask:

1.  Does it belong to AdilHoca?
2.  Is it readable in one second?
3.  Can a child understand it?
4.  Does it match previous assets?
5.  Is it production-ready?

If any answer is "No", revise.

------------------------------------------------------------------------

# 18. Long-Term Principle

Consistency is more important than artistic variety.

A player should immediately recognize any illustration, banner, icon,
badge or UI element as part of the AdilHoca universe.

This document is intended to evolve over time into the single source of
truth for the entire visual identity of the platform.

## Character Consistency Rules

Permanent traits (never change):
- Name
- Face shape
- Height
- Build
- Hair length
- Hair style
- Hair color
- Eye color
- Glasses (unless intentionally changed for a lesson)
- Overall facial identity

Variable traits:
- Clothing
- Accessories
- Pose
- Background
- Activity
- Facial expression
- Camera distance

For physical appearance lessons, ONLY the target feature may change. All other characteristics must remain identical.

## Expression Library
- Friendly smile
- Big cheerful smile
- Gentle soft smile
- Confident smirk
- Neutral / indifferent
- Slightly sad

Avoid identical facial expressions across groups of students. Small natural head tilts (5–10°) are encouraged while remaining front-facing.

## World Continuity

These 24 students are the permanent students of the AdilHoca universe and should reappear across grammar, vocabulary, reading, listening, games and story-based activities. Reuse these canonical characters instead of creating new students whenever possible.
